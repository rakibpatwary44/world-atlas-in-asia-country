# 🌍 WorldAtlas
Live link : https://worlds-altas.netlify.app/
<br/>
WorldAtlas is a responsive country exploration website built with React.  
Users can explore countries, view important information, and open a dedicated details page for each country.

## ✨ Features

- 🌎 Explore countries
- 🔎 Search and filter countries
- 🏳️ Display country flags
- 📍 View capital and subregion
- 👥 View population
- 📐 View country area
- 🗣️ Display languages
- 📄 Country details page
- 🧭 Dynamic routing
- ⚡ Loading state
- 📱 Responsive design
- 🎨 Modern dark-themed UI
- 🔗 React Router navigation

## 🛠️ Technologies Used

- React.js
- Vite
- Tailwind CSS
- Axios
- React Router DOM
- JavaScript (ES6+)
- REST API
